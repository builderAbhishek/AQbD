Set Up Plot Axes¶

The contour plot will be displayed in two dimensions. If there are more factors than axes, the levels of the other variables must be set to a constant so you can identify the appropriate slice of the design space. Consider using the Perturbation (or Trace) plot to choose the most significant factors to plot.

Change the factors used for the axes of the plot by right-clicking on a factor on the factors tool that floats over the graph. Use the same tool to set the constants for the other dimensions. Familiarity with this control will be helpful, as it is used throughout the software to manipulate slices in the factor space.

Another useful option for selecting axes or setting values is the Sheet view on the Factors tool palette. Simply click on Sheet and type in the desired levels.

To make more changes to the graphs, right-click on the graph and choose Edit Preferences. This provides a broad range of options such as controlling the axes tick marks, colorizing, shading, etc.

User Tip: If there are any categorical factors, the pull-down menu on the Factors tool provides the option of Average. Instead of choosing a specific level for the categorical factor, the responses will be averaged over all the levels for that factor.
