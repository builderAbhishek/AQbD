# AQbD Scope

## What This Software Does
- Statistically models Analytical Quality by Design workflows based on historical or experimental inputs.
- Computes Response Surfaces, Lack of Fit, ANOVA, and Multi-response Desirability.
- Determines the Method Operable Design Region (MODR) without boundary extrapolation.

## What This Software DOES NOT Do
- It does **not** perform physical laboratory experiments.
- It does **not** replace laboratory instruments (e.g., HPLC, GC).
- It does **not** automatically make a method regulatory compliant (it assists in generating aligned documentation).
- It is **not** currently Part 11 compliant (lacks audit trails and RBAC).
